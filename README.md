# Bookstore — Spring Data REST

## Локальный запуск на Mac

Распакуйте ZIP в отдельную папку. Откройте Terminal и перейдите в папку `bookstore-data-rest` внутри распакованного архива. Не запускайте команды из самого ZIP. Если папка уже существует, выберите другое место распаковки, чтобы не перезаписать свои изменения.

Нужен JDK 21. Проверьте `java -version`. Если JDK отсутствует, установите Temurin 21 для своей архитектуры Mac с https://adoptium.net/temurin/releases/?version=21 .

```bash
export JAVA_HOME="$(/usr/libexec/java_home -v 21)"
export PATH="$JAVA_HOME/bin:$PATH"
unset SPRING_PROFILES_ACTIVE
bash ./mvnw clean verify
bash ./mvnw spring-boot:run -Dspring-boot.run.arguments="--server.port=8083"
```

Дождитесь `Started BookstoreApplication`. Откройте http://localhost:8083/booklist . Включён Maven Wrapper — отдельная установка Maven не нужна. Первый запуск требует интернет.

Проверка во втором окне Terminal:

```bash
curl -i http://localhost:8083/books
curl -i http://localhost:8083/book/1
curl -i http://localhost:8083/api/books
```

Если порт 8083 занят, замените его в команде и адресах на другой, например 8092. Не завершайте чужие процессы.

По умолчанию используется H2 в памяти, MySQL не нужен. После перезапуска изменения в базе исчезают. Не включайте профиль mysql без отдельной настройки. Сервер доступен только локально; учебный API без авторизации не предназначен для публикации в интернет. Bootstrap и его лицензия сохранены.

Для остановки нажмите **Control+C**. Остановка сервера не удаляет файлы.

Исходники, тесты, настройки и краткая инструкция. Git-история и настройка удалённого репозитория не включены. Зависимости и результаты сборки устанавливаются/создаются локально. Лицензии сторонних компонентов сохранены. Это техническое описание комплекта, не заявление о самостоятельном авторстве пользователя.
